# 千丝万缕 1.1.4 使用说明

## 第一次打开

直接覆盖安装新版，不要先卸载旧版。首次打开需要联网，并按你目前使用的方式开启 VPN。输入店主账号密码，可勾选「自动登录」，点击「登录」。软件自动准备这家店的会员、卡余额、服务项目和完整流水，无需额外操作。勾选后再次打开会直接进入本地账本，可以断网操作；不勾选则需要输入账号密码解锁本地账本。默认不勾选，主动退出登录会取消自动登录，下次需要重新输入密码。选择保存在手机加密配置中，不保存明文密码；共用手机时请按实际需要选择。

## 平时记账

如果云端更换了店主账号或密码，手机第一次使用新凭证时需联网并开启 VPN。软件在本地验证失败后核对云端账号，同一门店验证通过后更新本机凭证，保留原账本和待同步记录，不会自动同步。此后新账号可离线登录。其他门店的账号不会替换这台手机的账本。

会员登记、办卡、充值、划卡、撤销、会员删除/恢复及店铺设置都先保存到本机加密文件。姓名和手机号选一项登记，一位会员一张储值卡。余额未结清不能删除会员；删除后可以恢复，原流水保留。

首页上方显示云端状态、待同步数量和上次同步时间。没有网络或 VPN 不通时会显示「未连接至云端」，仍可打开、查询和记账。

- 右侧重试图标：只检查连接，不上传或下载账目。
- 「双向同步」：上传本机待同步修改，再下载云端最新账本。
- 联网本身不会自动同步；建议营业结束时手动同步一次。
- 同步失败会保留本机数据和待同步操作，可稍后再试。重复重试同一批不会重复扣款。

## 家人一起使用

目前是单店系统：同一账号登录的手机管理同一家店。各手机必须手动同步，才能看到其他手机新记的账。不支持家人各自店铺数据隔离。

如果两台手机离线操作了同一张卡，同步时可能提示冲突。点「查看同步核对方案」，检查本机余额、云端余额和合并后余额；确认后再点「双向同步」。核对不会立即上传。余额不足、重复手机号或重复办卡等不能直接合并的情况，会保留本机记录并提示原因，需要先核对实际业务后由维护人员处理。

建议同一笔业务只由一台手机记账；系统能避免同一操作重试重复入账，不能识别两个人各自录入的同一笔生意。

## 数据放在哪里

「设置 → 数据存储」可查看本地文件位置、设备内恢复副本位置和固定云端地址。默认文件在这台手机的应用私有目录内，不是电脑 E 盘。

点「更换本地存放目录」，在安卓系统选择器中选文件夹。应用会先复制、核对现有加密账本，成功后才切换，并继续保留应用私有目录内的恢复副本。指定目录不可用时会显示提示，并使用恢复副本继续保存。可点「改回应用私有目录」。切换目录不等于云端同步，也不会删除原目录副本。

本地文件使用 Android Keystore 的设备密钥及 AES-GCM 加密；离线登录保存加盐密码校验值，不保存明文密码。文件绑定当前应用在这台手机上的密钥，仅复制 `.qsledger` 文件不能在另一台手机解密。卸载、清除应用数据或换手机前，请先完成云端同步。尚未同步的数据没有云端副本。CSV 导出是明文账目报表，请妥善保管。

云端仍在你的独立 Cloudflare 账号内，见 `cloud/owned.json`。同步需要云端会话；登录过期可在数据存储中点「重新验证云端账号」，输入密码后重试连接，尚未同步的本机账目不会被替换。云端地址不是任意可改的同步目标，迁移服务需要维护人员修改配置并重新打包。

## 维护与测试

源码在 `E:\baberShop`。安卓界面打包在 APK 内，修改界面或离线逻辑需要构建并覆盖安装新 APK；只部署云端不能更新已装的本地页面。

- `npm test`：30 项账务、数据库约束和同步规则测试。
- `npm run typecheck`：类型检查。
- `npm run build`：构建云端服务。
- `npm run build:offline`：构建 APK 内的离线界面。
- `tests/salon-sync-integration.mjs`：仅对本机隔离 Wrangler 数据库测试同步 API。
- `tests/salon-offline-client-integration.mjs`：仅对本机隔离数据库测试实际客户端队列、响应丢失重试及冲突核对。
- `android/offlinetests`：独立包名的合成数据测试；不操作真实应用账本。

Cloudflare 现有数据库已应用 0000 至 0004 迁移。后续只执行新的迁移文件，不要重复执行旧文件。更新数据库前先按 `cloud/README.md` 加密备份；更新 APK 必须沿用原签名。
