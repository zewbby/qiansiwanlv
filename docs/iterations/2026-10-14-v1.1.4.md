# 1.1.4 账号变更后无法登录修复

日期：2026-10-14。包名：`com.barbershop.app`。versionCode：9。

## 问题与改动

- 已初始化手机的登录页面只调用本地密码校验。云端换了管理员账号后，本地仍使用旧 `admin` 校验值，导致新账号提示密码错误；手机登录页也显示旧账号。
- 新增原生统一登录流程：有效本地凭证保持离线验证；本地凭证不匹配或本地尝试限制触发时，改为云端登录及门店校验。
- 云端通过且门店相同时原子更新加密账号元数据；不重新初始化已有账本，不替换待同步操作。元数据写入失败恢复原内存配置。
- 密码不正确、网络不可用或门店不匹配时拒绝登录并保留原配置；网络失败提示检查网络和 VPN。云端原有登录限流继续生效。
- 读取账本供界面显示时使用当前本地账号，避免更换账号后仍显示旧用户名。
- 保留自动登录勾选机制。新凭证更新后可离线登录；初次设备仍按原流程初始化云端账本。
